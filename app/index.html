Chemical families

Field guide

Choose Blocks or Bohr models to see the same groups and periods. Drag horizontally or vertically for a full turn, Shift-drag to pan, and use + or − to zoom.

Read the height

Positive and negative place values on opposite sides of the grid. Above / below median places the middle value at zero. Atomic number uses a square-root scale. Other properties use a linear scale. A dim element on the grid has no applicable value and can still be selected.

Inspect an atom

Click once to select, then click the same element again to dissolve the table along its Fibonacci paths and open its record. Search with /, or use arrows on the table and Enter. In detail view, drag or use the arrow keys to rotate the atom. Escape returns to the table.

Shell populations come from the element records. Paths, distances and nucleus geometry are schematic. The optional period-eight entries are theoretical.
